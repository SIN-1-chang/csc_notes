    1 回溯法的基本原理与通用框架 (Rationale and General Template)¶

    1.1 从暴力枚举到回溯剪枝 (Brute Force vs. Pruning)¶

    在算法设计中，我们始终围绕两个核心诉求：有效性（Effectiveness，保证找到正确解或近似/高概率解）与高效率（Efficiency，保证运行时间尽可能短）。

    当求解一个组合搜索或约束满足问题时，最稳妥的方法是暴力搜索 / 蛮力法（Exhaustive Search / Brute Force）：生成所有候选解（Candidate answers）的列表并逐一检验。只要候选集有限，蛮力法必然有效，但候选解空间（Solution space）往往随问题规模呈指数级或阶乘级爆炸，效率极低。

    回溯法（Backtracking）的核心思想： 我们将待求的解表示为向量 \((x_1, x_2, \dots, x_n)\)，其中每个分量 \(x_k \in S_k \ (1 \le k \le n)\)。回溯法采用逐步构造部分解（Partial solution）\((x_1, \dots, x_i)\) 的方式： 1. 在第 \(i+1\) 步，尝试从候选集 \(S_{i+1}\) 中取出一个元素 \(x_{i+1}\) 加入部分解，形成 \((x_1, \dots, x_i, x_{i+1})\)； 2. 剪枝检测（Pruning）：立即检查 \((x_1, \dots, x_i, x_{i+1})\) 是否满足问题的约束条件 \(R\)： - 若满足（"Yes"），则继续向下递归扩展下一个分量 \(x_{i+2}\)； - 若不满足（"No"），说明以 \((x_1, \dots, x_{i+1})\) 为前缀的整棵子树下的所有候选解均不可能合法，直接将其全部跳过（即剪枝 Pruning），删去 \(x_{i+1}\) 并尝试 \(S_{i+1}\) 中的下一个候选值； - 若 \(S_{i+1}\) 中的所有候选值均已尝试失败，则撤销 \(x_i\)，回溯（Backtrack）到上一层部分解 \((x_1, \dots, x_{i-1})\)。

    \[\text{Backtracking} = \text{DFS（深度优先后序遍历）} + \text{Pruning（约束剪枝）}\]
    • 抽象状态树与空间优势（板书 W5 Page 1 & PPT Slide 6）： 回溯过程在逻辑上等价于对一棵抽象状态树（Game tree / Search tree）执行深度优先搜索（DFS / Post-order traversal）。注意：在内存中并不需要真正建立这棵树，只需维护当前从根到叶子的单一路径状态，因此空间复杂度仅为树高 \(O(h)\)（而如果改用广度优先搜索 BFS，空间复杂度将高达指数级的 \(O(n_{\text{nodes}})\)）。

    1.2 回溯法通用模板与搜索顺序优化¶

    在老师手写板书（W5 Pages 1–2）中，将回溯搜索归纳为四类常见目标：① 判断是否存在合法路径（Is there a good path?）；② 找出一条合法路径（Find a good path）；③ 统计合法路径总数（# good paths）；④ 找出所有合法路径（Find all good paths）。

    课程组 PPT（Slide 10）给出的寻找单解的标准回溯算法通用模板如下：

    bool Backtracking(int i) {
    bool Found = false;
    if (i > N)
        return true; /* solved with (x_1, ..., x_N) */
    for (each x_i in S_i) {
        /* check if partial solution satisfies the restriction R */
        OK = Check((x_1, ..., x_i), R); /* pruning! */
        if (OK) {
            Count x_i in;               /* 更新状态，记录当前选择 x_i */
            Found = Backtracking(i + 1);
            if (!Found)
                Undo(i);                /* 回溯：撤销本次修改，恢复到 (x_1, ..., x_{i-1}) */
        }
        if (Found) break;               /* 若只需找一解，找到后立即跳出循环逐层返回 */
    }
    return Found;
}

    搜索顺序优化原则：小候选集优先（"Smaller \(S_i\) first"，PPT Slide 11 & 讲义 §6.4） 当不同决策变量 \(x_i\) 的候选集合大小 \(\vert{}S_i\vert{}\) 不同时，应当优先确定候选集合 \(\vert{}S_i\vert{}\) 较小的变量！

    • 定量对比实例：设三个变量分别取自 \(\vert{}S_a\vert{} = 2, \ \vert{}S_b\vert{} = 3, \ \vert{}S_c\vert{} = 4\)（叶子总数恒为 \(2 \times 3 \times 4 = 24\)）：
    • 策略 A（从小到大先选 \(a\)，再选 \(b\)，最后选 \(c\)）：各层节点数依次为 \(1 \to 2 \to 6 \to 24\)，整棵搜索树共有 \(1 + 2 + 6 + 24 = \mathbf{33}\) 个节点（内部节点仅 \(9\) 个）；
    • 策略 B（从大到小先选 \(c\)，再选 \(b\)，最后选 \(a\)）：各层节点数依次为 \(1 \to 4 \to 12 \to 24\)，整棵搜索树共有 \(1 + 4 + 12 + 24 = \mathbf{41}\) 个节点（内部节点达 \(17\) 个）。
    • 物理直观：越早固定分支因子小的变量，上层内部节点的基数就越小；一旦在浅层发生剪枝，被一刀剪掉的下层子树规模反而越大，从而显著减少状态树中被实际访问的节点总数。

    回溯算法常见时间复杂度的渐近阶比较（讲义 §6.2）

    对于任意固定常数 \(a > 1, \ b > 0\)，当 \(n \to \infty\) 时，多项式、指数、阶乘与 \(n^n\) 满足严格的渐近大小关系（可通过比值判别法与斯特林公式 \(n! \sim \sqrt{2\pi n}\left(\frac{n}{e}\right)^n\) 证明）： $\(\lim_{n \to \infty} \frac{n^b}{a^n} = \lim_{n \to \infty} \frac{a^n}{n!} = \lim_{n \to \infty} \frac{n!}{n^n} = 0 \implies O(n^b) \ll O(a^n) \ll O(n!) \ll O(n^n)\)$

    2 经典问题一：八皇后与 \(N\) 皇后问题 (Eight Queens / \(N\)-Queens)¶

    2.1 问题建模与解空间缩减¶

    问题描述：在 \(8 \times 8\)（或一般地 \(n \times n\)）国际象棋棋盘上放置 \(8\)（或 \(n\)）个皇后，使得任意两个皇后都不能相互攻击（即任意两个皇后不能处于同一行、同一列、同一条主对角线或同一条副对角线上）。

    数学建模與约束提取（PPT Slide 4）： 由于每一行必须且只能放置一个皇后，令 \(Q_i\) 表示第 \(i\) 行的皇后，用决策变量 \(x_i\) 表示第 \(i\) 行皇后所在的列号（\(1 \le i \le n\)）。由此得到三条约束条件：

    1. 行与边界约束：每个 \(x_i \in S_i = \{1, 2, \dots, n\}\)（仅利用此条件，初始解空间大小为 \(n^n\)，对 \(8\) 皇后为 \(8^8 = 16,777,216\)）；
    2. 不同列约束：当 \(i \neq j\) 时，必须满足 \(x_i \neq x_j\)。这意味着合法解 \((x_1, x_2, \dots, x_n)\) 必然是 \(1, 2, \dots, n\) 的一个全排列（Permutation）！仅此一条约束就将候选解空间从 \(n^n\) 大幅缩减至 \(n!\)（对 \(8\) 皇后降为 \(8! = 40,320\)，对 \(4\) 皇后仅为 \(4! = 24\)）；
    3. 不同对角线约束（剪枝条件）：任意两个皇后 \((i, x_i)\) 与 \((j, x_j)\) 不能位于同一条 \(45^\circ\) 或 \(135^\circ\) 对角线上，等价于它们相隔的行数不能等于相隔的列数： $\(\frac{x_i - x_j}{i - j} \neq \pm 1 \iff \vert{}x_i - x_j\vert{} \neq \vert{}i - j\vert{} \iff \begin{cases} i - x_i \neq j - x_j & (\text{主对角线 }\backslash\text{ 方向}) \\ i + x_i \neq j + x_j & (\text{副对角线 }/\text{ 方向}) \end{cases}\)$

    四皇后问题（4-Queens）搜索树追踪（PPT Slides 5–6）： - 若选择第一行放在第 1 列（\(x_1 = 1\)）： - 试 \(x_2 = 2\)：\(\vert{}2-1\vert{} = \vert{}2-1\vert{}\)，主对角线冲突，立即剪枝； - 试 \(x_2 = 3\)：下一层剩 \(\{2, 4\}\)，试 \(x_3 = 2\)（与 \(x_2=3\) 副对角线冲突剪枝），试 \(x_3 = 4\)（与 \(x_2=3\) 主对角线冲突剪枝），回溯； - 试 \(x_2 = 4\)：下一层试 \(x_3 = 2\) 合法，但到第四行唯一剩余的 \(x_4 = 3\) 与 \(x_3 = 2\) 冲突剪枝。至此 \(x_1 = 1\) 分支全部失败！ - 回溯改选 \(x_1 = 2 \to x_2 = 4 \to x_3 = 1 \to x_4 = 3\)，成功找到第一个合法解 (2, 4, 1, 3)；同理在 \(x_1 = 3\) 分支下可找到镜像对称的第二个合法解 (3, 1, 4, 2)。

    2.2 递归算法实现、非递归栈式实现与复杂度分析¶

    1. 递归版实现（利用三个布尔标记数组实现 \(O(1)\) 冲突检测，讲义算法 6.1）

    为了在 \(O(1)\) 时间内判断格子 \((r, c)\) 的列、主对角线（左上到右下，\(r - c\) 为常数，加偏移量 \(n\) 映射为下标 \(a = r - c + n \in [1, 2n-1]\)）和副对角线（右上到左下，\(b = r + c \in [2, 2n]\)）是否已被占用，维护三个全局布尔数组 col、diag1 和 diag2：

    /* 全局状态数组：x[1..n] 存各行皇后的列号；col, diag1, diag2 初始全为 false */
void Queens(int r, int n) {
    if (r == n + 1) {
        PrintSolution(x, n); /* 前 n 行均已合法放好，输出当前解 x[1..n] */
        return;
    }
    for (int c = 1; c <= n; c++) {
        int a = r - c + n;   /* 主对角线编号 (1 .. 2n-1) */
        int b = r + c;       /* 副对角线编号 (2 .. 2n) */
        if (!col[c] && !diag1[a] && !diag2[b]) { /* O(1) 剪枝检查 */
            x[r] = c;
            col[c] = diag1[a] = diag2[b] = true;

            Queens(r + 1, n); /* 递归放置下一行 */

            /* Undo: 回溯恢复现场 */
            x[r] = 0;
            col[c] = diag1[a] = diag2[b] = false;
        }
    }
}

    2. 老师手写板书版：非递归（迭代式）回溯算法 NQ(n)（ADS26W5.pdf Pages 2–3）

    在课堂板书中，老师给出了不依赖系统调用栈的纯 while 循环迭代回溯写法：用 P[i] 记录第 \(i \ (0 \le i < n)\) 行当前放置的列号（初始全为 -1）。每次在当前行 \(i\) 从 P[i] + 1 开始向右寻找下一个不与前 \(i-1\) 行冲突的列号 \(j\)；若找到则前进到下一行 i = i + 1，若找不到则将 P[i] 重置为 -1 并回退到上一行 i = i - 1：

    /* 老师板书 N-Queens 非递归迭代回溯实现 (0-indexed: 行/列范围 0 .. n-1) */
bool NQ(int n, int P[]) {
    for (int k = 0; k < n; k++) P[k] = -1;
    int i = 0;
    while (i >= 0 && i < n) {
        bool find_feasible = false;
        for (int j = P[i] + 1; j <= n - 1; j++) {
            /* 检查 (i, j) 是否与前面已放好的 P[0 ... i-1] 发生列或对角线冲突 */
            if (CannotAttack(P, i, j)) {
                P[i] = j;
                find_feasible = true;
                break;
            }
        }
        if (find_feasible) {
            i = i + 1;       /* 当前行成功放置，推进到下一行 */
        } else {
            P[i] = -1;       /* 当前行已无合法列可选，重置当前行 */
            i = i - 1;       /* Backtrack: 回退到上一行尝试下一个候选列 */
        }
    }
    if (i == -1) return false; /* no feasible solution */
    return true;               /* i == n: 成功返回一组可行解 P[0..n-1] */
}

    3. 节点总数与时间复杂度上界证明： 若仅考虑不同列约束，第 \(r\) 层至多有 \(n(n-1)\cdots(n-r+1) = \frac{n!}{(n-r)!}\) 个节点。因此搜索树中实际访问的节点总数 \(N_{\text{visited}}\) 严格满足：

    \[N_{\text{visited}} \le \sum_{r=0}^n \frac{n!}{(n - r)!} = n! \sum_{j=0}^n \frac{1}{j!} < e \cdot n! < 3n! = O(n!)\]

    在每个节点处尝试 \(n\) 列（每次 \(O(1)\) 检查），故包含输出所有解在内的最坏总时间上界为 \(O(n \cdot n!)\)。

    3 经典问题二：收费公路重建问题 (The Turnpike Reconstruction Problem)¶

    3.1 问题描述与最大剩余距离端点性质¶

    问题描述（PPT Slide 7 & 板书 W5 Page 4）： 设 \(x\) 轴上有 \(N\) 个点（公路出口），其坐标按递增顺序排列为 \(x_1 < x_2 < \dots < x_N\)。由于整体平移不改变点对之间的距离，不妨固定最左端点为原点 \(x_1 = 0\)。 这 \(N\) 个点两两之间共形成 \(\dfrac{N(N - 1)}{2}\) 个正距离，将它们从小到大存放在距离多重集（Multiset）\(D\) 中。我们的任务是：仅根据给定的距离多重集 \(D\)，反推重建出所有点的坐标集合 \(X = (x_1, x_2, \dots, x_N)\)。

    核心突破口（Key Observation，板书 W5 Page 5）： 1. 确定点数 \(N\) 与两端点 \(x_1, x_N\)： 由 \(\vert{}D\vert{} = \frac{N(N-1)}{2}\) 可直接算出点数 \(N\)。全集 \(D\) 中最大的那个距离 \(W = \max(D)\) 必然是最左端点 \(x_1\) 与最右端点 \(x_N\) 之间的距离！因此可直接固定 \(x_1 = 0, \ x_N = W\)，并将 \(W\) 从 \(D\) 中删去一份。 2. 中间任意时刻的最大剩余距离 \(d_{\max} = \max(D)\)： 在后续放置过程中，假设我们已经从左右两端向中间确定了左侧前缀 \(x_1, \dots, x_{\text{left}-1}\) 和右侧后缀 \(x_{\text{right}+1}, \dots, x_N\)（它们两两之间的距离均已从 \(D\) 中扣除）。 此时，剩余多重集 \(D\) 中的最大距离 \(d_{\max} = \max(D)\)，必然产生于某个尚未放置的点 \(a^*\) 与最左端点 \(x_1 = 0\) 或最右端点 \(x_N\) 之间！（因为任何未放点都在区间 \((0, x_N)\) 内部，它到其它点的距离绝不可能超过它到两端点 \(0\) 或 \(x_N\) 的距离）。 因此，当前每一步至多只有两个候选位置（Branching factor \(\le 2\)）： - Option 1（距左端点 \(x_1 = 0\) 为 \(d_{\max}\)）：尝试将该点放在右侧空位 \(x_{\text{right}} = d_{\max}\)； - Option 2（距右端点 \(x_N\) 为 \(d_{\max}\)）：尝试将该点放在左侧空位 \(x_{\text{left}} = x_N - d_{\max}\)。

    3.2 课堂 6 点实例完整回溯追踪¶

    例题（PPT Slide 7）：给定距离多重集 \(D = \{1, 2, 2, 2, 3, 3, 3, 4, 5, 5, 5, 6, 7, 8, 10\}\)（共 \(15\) 个距离），重建点集。

    1. Step 1（确定 \(N\)）：由 \(\frac{N(N-1)}{2} = 15 \implies N = 6\)。
    2. Step 2（固定两端点）：最大距离为 \(10\)，故置 \(x_1 = 0, \ x_6 = 10\)，从 \(D\) 中删去 \(10\)。当前待填区间为 left = 2, right = 5。
    3. Step 3（逐层选最大剩余距离并回溯检验）：
    4. 第 1 层（\(\max(D) = 8\)，候选为 \(x_5 = 8\) 或 \(x_2 = 10 - 8 = 2\)，对称选 \(x_5 = 8\)）： 检查 \(x_5 = 8\) 到已放点 \(\{0, 10\}\) 的距离：\(\vert{}8 - 0\vert{} = 8, \ \vert{}8 - 10\vert{} = 2\)，均在 \(D\) 中。扣除 \(\{2, 8\}\)，剩余 \(D = \{1, 2, 2, 3, 3, 3, 4, 5, 5, 5, 6, 7\}\)，已放点为 \(\{0, 8, 10\}\)（left = 2, right = 4）。
    5. 第 2 层（\(\max(D) = 7\)，候选为 Option 1: \(x_4 = 7\) 或 Option 2: \(x_2 = 10 - 7 = 3\)）：
      • 先试左分支 Option 1（\(x_4 = 7\)）：到 \(\{0, 8, 10\}\) 的距离为 \(\{7, 1, 3\}\)，均在 \(D\) 中！扣除后剩余 \(D = \{2, 2, 3, 3, 4, 5, 5, 5, 6\}\)，已放点为 \(\{0, 7, 8, 10\}\)（left = 2, right = 3）。
      • 进入第 3 层（\(\max(D) = 6\)，候选为 \(x_3 = 6\) 或 \(x_2 = 10 - 6 = 4\)）：
        • 若试 \(x_3 = 6\)：需要距离 \(\vert{}6 - 7\vert{} = 1\)，但此时 \(D\) 中唯一的 \(1\) 刚才已被 \(x_4 = 7\) 用掉了（\(1 \notin D\)），剪枝失败！
        • 若试 \(x_2 = 4\)：需要距离 \(\vert{}4 - 0\vert{} = 4\) 和 \(\vert{}4 - 8\vert{} = 4\)（共需两份 \(4\)），但 \(D\) 中只有一份 \(4\)，剪枝失败！
      • 两个分支均失败，说明 \(x_4 = 7\) 是死胡同！执行 Undo 回溯，将 \(x_4 = 7\) 撤除，并把 \(\{7, 1, 3\}\) 重新插回 \(D\)！
      • 改试右分支 Option 2（\(x_2 = 3\)）：到 \(\{0, 8, 10\}\) 的距离为 \(\{3, 5, 7\}\)，均在 \(D\) 中。扣除后剩余 \(D = \{1, 2, 2, 3, 3, 4, 5, 5, 6\}\)，已放点为 \(\{0, 3, 8, 10\}\)（left = 3, right = 4）。
    6. 第 3 层（在 \(x_2 = 3\) 下，\(\max(D) = 6\)，候选为 \(x_3 = 10 - 6 = 4\) 或 \(x_4 = 6\)）：
      • 若试 \(x_3 = 4\)：需要 \(\vert{}4 - 3\vert{} = 1\) 和 \(\vert{}4 - 8\vert{} = 4, \ \vert{}4 - 10\vert{} = 6, \ \vert{}4 - 0\vert{} = 4\)（需要两份 \(4\)，不足），剪枝失败；
      • 改试 \(x_4 = 6\)：到 \(\{0, 3, 8, 10\}\) 的距离为 \(\{6, 3, 2, 4\}\)，全部在 \(D\) 中！扣除后剩余 \(D = \{1, 2, 3, 5, 5\}\)，已放点为 \(\{0, 3, 6, 8, 10\}\)（left = 3, right = 3）。
    7. 第 4 层（\(\max(D) = 5\)，候选 \(x_3 = 5\)）： 到 \(\{0, 3, 6, 8, 10\}\) 的距离为 \(\{5, 2, 1, 3, 5\}\)，恰好将剩余的 \(D\) 完全清空（Is_Empty(D) == true）！
    8. 最终重建结果：X = (0, 3, 5, 6, 8, 10)（注：其左右镜像翻转 (0, 2, 4, 5, 7, 10) 具有完全相同的距离集 \(D\)）。

    3.3 算法代码实现、复杂度分析与多项式生成函数视角¶

    /* X[1]...X[left-1] 和 X[right+1]...X[N] 已经确定；D 为剩余距离多重集 */
bool Reconstruct(DistType X[], DistSet D, int N, int left, int right) {
    bool Found = false;
    if (Is_Empty(D))
        return true; /* solved! */
    DistType D_max = Find_Max(D);

    /* Option 1: 尝试放在右侧空位 X[right] = D_max */
    /* Check 检查对所有已确定的 X[i]，|D_max - X[i]| 在 D 中是否有足够份数 (pruning) */
    bool OK = Check(D_max, N, left, right);
    if (OK) { /* add X[right] and update D */
        X[right] = D_max;
        for (int i = 1; i < left; i++)       Delete(|X[right] - X[i]|, D);
        for (int i = right + 1; i <= N; i++) Delete(|X[right] - X[i]|, D);

        Found = Reconstruct(X, D, N, left, right - 1);

        if (!Found) { /* if does not work, undo! */
            for (int i = 1; i < left; i++)       Insert(|X[right] - X[i]|, D);
            for (int i = right + 1; i <= N; i++) Insert(|X[right] - X[i]|, D);
        }
    } /* finish checking option 1 */

    if (!Found) { /* if option 1 does not work, try Option 2: X[left] = X[N] - D_max */
        OK = Check(X[N] - D_max, N, left, right);
        if (OK) {
            X[left] = X[N] - D_max;
            for (int i = 1; i < left; i++)       Delete(|X[left] - X[i]|, D);
            for (int i = right + 1; i <= N; i++) Delete(|X[left] - X[i]|, D);

            Found = Reconstruct(X, D, N, left + 1, right);

            if (!Found) { /* undo */
                for (int i = 1; i < left; i++)       Insert(|X[left] - X[i]|, D);
                for (int i = right + 1; i <= N; i++) Insert(|X[left] - X[i]|, D);
            }
        } /* finish checking option 2 */
    } /* finish checking all the options */
    return Found;
}

    时间复杂度分析（教师版 PPT Slide 7 & 板书 W5 Page 6）： - 若用平衡二叉搜索树（如 AVL 树或红黑树）维护距离多重集 \(D\)（至多含 \(O(N^2)\) 个元素），则单次 Find_Max、Insert、Delete 耗时均为 \(O(\log(N^2)) = O(\log N)\)。 - 每递归一层需检查并增删 \(O(N)\) 个距离，单节点处理耗时为 \(O(N \log N)\)。 - 最坏情况（Worst-case）：搜索树深度为 \(N - 2\)，每个节点至多有 \(2\) 个分支，故至多有 \(O(2^N)\) 个节点，最坏时间复杂度为 \(O(2^N N \log N)\)； - 平均情况 / 无回溯撤销情况（Average-case）：在绝大多数随机实例中，错误分支会在 \(O(1)\) 步内因距离不匹配而立即被 Check 剪枝，几乎不需要回溯撤销，总共只访问 \(O(N)\) 个节点，此时运行时间仅为 \(O(N^2 \log N)\)！

    点击展开：老师手写板书补充（ADS26W5 Pages 6–7）——收费公路问题的生成函数与多项式乘法视角

    在课堂板书中，老师展示了如何用特征多项式（Generating Function）将点集之间的加减运算转化为多项式乘法：

    1. 两个集合之和 \(A + B = \{a + b : a \in A, b \in B\}\) 的快速计算： 设整数集合 \(A = \{a_1, \dots, a_n\}, \ B = \{b_1, \dots, b_n\}\)，最大值记为 \(M\)。若直接两两枚举求和需 \(O(n^2)\) 时间。 构造多项式 \(F_A(x) = \sum_{i=1}^n x^{a_i}\) 与 \(F_B(x) = \sum_{j=1}^n x^{b_j}\)。将两多项式相乘： $$ F_A(x) \cdot F_B(x) = \left(\sum_{i=1}^n x^{a_i}\right)\left(\sum_{j=1}^n x^{b_j}\right) = \sum_{i, j} x^{a_i + b_j} $$ 乘积多项式中 \(x^k\) 项的系数，恰好就是 \(a_i + b_j = k\) 出现的重数！利用第七章的快速傅里叶变换（FFT），可在 \(O(M \log M)\) 时间内算出该多项式乘积。
    2. 收费公路重建的多项式方程： 对于点集 \(A = \{a_1, a_2, \dots, a_n\}\)，考察差集 \(A - A = \{a_i - a_j : a_i, a_j \in A\}\)。它由三部分组成：\(n\) 个自身相减的 \(0\)、正距离多重集 \(D(A)\) 以及负距离多重集 \(-D(A)\)。 因此，定义洛朗多项式 \(F_A(x) = \sum_{i=1}^n x^{a_i}\)、\(F_A(x^{-1}) = \sum_{j=1}^n x^{-a_j}\) 以及距离多项式 \(F_D(x) = \sum_{d \in D} x^d\)，则恒有代数恒等式： $$ F_A(x) \cdot F_A(x^{-1}) = n + F_D(x) + F_D(x^{-1}) $$ 收费公路重建问题在代数上等价于：已知右侧的多项式 \(n + F_D(x) + F_D(x^{-1})\)，对其做因式分解求回多项式 \(F_A(x)\)（已知存在 \(\text{poly}(n, M)\) 的伪多项式时间算法，但该问题是否存在关于 \(n\) 和 \(\log M\) 的强多项式时间算法至今仍是著名开放问题）。

    4 博弈树、极小化极大策略与 \(\alpha\text{-}\beta\) 剪枝 (Games and \(\alpha\text{-}\beta\) Pruning)¶

    4.1 井字棋 (Tic-tac-toe)、估值函数与 Minimax 策略¶

    在以井字棋（Tic-tac-toe，在 \(3 \times 3\) 棋盘上双方轮流画 \(\text{X}\) 和 \(\text{O}\)，先在行、列或对角线连成三子者获胜）为代表的双人完全信息确定性零和博弈（Zero-sum game）中： - 井字棋共有 \(3^9 = 19,683\) 种盘面布局（每个格子可为 \(\text{X}\)、\(\text{O}\) 或空），共有 \(9! = 362,880\) 种不同的落子对局序列。 - 对于国际象棋或围棋等复杂博弈，完整博弈树过于庞大，无法搜索至终局，必须限制搜索深度并引入启发式估值函数（Evaluation Function）\(f(P)\) 来量化盘面 \(P\) 的优劣（Goodness）。

    1. 井字棋的估值函数设计（PPT Slide 14）

    定义盘面 \(P\) 的估值函数 \(f(P)\) 为：

    \[ f(P) = W_{\text{Computer}} - W_{\text{Human}} \]

    其中 \(W\) 表示在当前盘面 \(P\) 下，该方尚未被对手棋子堵死的潜在获胜连线（行、列、对角线，全盘共 \(8\) 条）的数量。 - 计算实例：设 \(3 \times 3\) 棋盘上，Computer（执 \(\text{O}\)）下在正中心 \((2,2)\)，Human（执 \(\text{X}\)）下在第一行正中 \((1,2)\)： - Computer 的潜在获胜线：第一行和中间列因已有对手的 \(\text{X}\) 而被堵死（损失 \(2\) 条），其余 \(8 - 2 = 6\) 条线仍可获胜，故 \(W_{\text{Computer}} = 6\)； - Human 的潜在获胜线：正中心被 Computer 的 \(\text{O}\) 占据，穿过正中心的中间行、中间列及两条对角线共 \(4\) 条线均被堵死，仅剩外围 \(8 - 4 = 4\) 条线，故 \(W_{\text{Human}} = 4\)； - 当前盘面估值为 \(f(P) = 6 - 4 = 2 > 0\)（Computer 占优）。

    2. 极小化极大策略（Minimax Strategy，PPT Slides 14–15）

    在零和博弈中，两方的目标完全相反： - MAX 节点（轮到 Computer 落子）：Computer 总是选择能使盘面估值 \(f(P)\) 最大化（Maximize）的子节点； - MIN 节点（轮到 Human 落子）：理性对手 Human 总是选择能使 Computer 的盘面估值 \(f(P)\) 最小化（Minimize）的子节点。

    因此，在博弈树上执行后序 DFS 遍历：叶节点直接计算 \(f(P)\)，内部 MIN 节点取所有孩子估值的 \(\min\)，内部 MAX 节点取所有孩子估值的 \(\max\)，逐层向上回传。

    4.2 \(\alpha\text{-}\beta\) 剪枝 (\(\alpha\text{-}\beta\) Pruning)¶

    在按深度优先（从左到右）遍历博弈树计算 Minimax 值的过程中，许多分支无需完全展开即可断定其绝不可能影响根节点的最终决策，这种利用已算出的上下界提前截断无效分支的技术称为 \(\alpha\text{-}\beta\) 剪枝：

    剪枝类型 发生的节点位置 剪枝触发条件与逻辑推导（对照 PPT Slides 16–17）
    \(\alpha\) 剪枝
    （\(\alpha\) pruning）    		 发生在 MIN 节点处
    （其父/祖先 MAX 节点已拥有保底值 \(\alpha\)）    		 设父节点为 MAX，其左子树已算出值 \(\alpha = 44\)（故父节点最终值至少 \(\ge 44\)）。
    现搜索右孩子（MIN 节点）：当算出该 MIN 节点的第一个孩子值为 \(40\) 时，由于 MIN 节点取最小值，该 MIN 节点的最终值必定 \(\le 40\)！
    既然 \(40 < 44\)，父节点 MAX 绝不会选择这个 \(\le 40\) 的右孩子，因此该 MIN 节点剩余的所有未访问孩子（黑球分支）可被立即剪除！
    \(\beta\) 剪枝
    （\(\beta\) pruning）    		 发生在 MAX 节点处
    （其父/祖先 MIN 节点已拥有上界值 \(\beta\)）    		 设父节点为 MIN，其左子树已算出值 \(\beta = 44\)（故父节点最终值至多 \(\le 44\)）。
    现搜索右孩子（MAX 节点）：当算出该 MAX 节点的第一个孩子值为 \(68\) 时，由于 MAX 节点取最大值，该 MAX 节点的最终值必定 \(\ge 68\)！
    既然 \(68 > 44\)，父节点 MIN 绝不会选择这个 \(\ge 68\) 的右孩子，因此该 MAX 节点剩余的所有未访问孩子（黑球分支）可被立即剪除！
    • 通用维护法则：在 DFS 向下传递时，维护两个界 \([\alpha, \beta]\)：
    • \(\alpha\)：当前路径上所有祖先 MAX 节点目前已知的最大保底值（MAX 的下界，初始为 \(-\infty\)）；
    • \(\beta\)：当前路径上所有祖先 MIN 节点目前已知的最小上界值（MIN 的上界，初始为 \(+\infty\)）；
    • 一旦在任意节点处出现 \(\alpha \ge \beta\)（即当前节点的取值区间彻底跌破了祖先的容忍窗口），立即停止遍历该节点的剩余孩子并回溯剪枝！
    • \(\alpha\text{-}\beta\) 剪枝的惊人效率（PPT Slide 17 核心结论）： 当同时结合 \(\alpha\) 剪枝与 \(\beta\) 剪枝时，在实践（及理想启发式着法排序）中，它能将需要搜索的节点总数从完整博弈树的 \(N\) 个节点缩减至仅需搜索 \(O(\sqrt{N})\) 个节点！这意味着在相同的算力时间内，搜索引擎向后看（Look-ahead）的博弈树深度可以直接翻倍！

    Problem Statement: - Ex 6.1: 在五皇后（\(5 \times 5\) 棋盘）的所有合法摆法中，至少有一个皇后位于棋盘角点（Corner）的摆法共有几种？ - Ex 6.2: 在 \(B \times B\) 的国际象棋棋盘上，马从 \((R, C)\) 可跳到 \((R', C')\) 当且仅当 \((|R - R'|, |C - C'|) \in \{(2, 1), (1, 2)\}\)。一次“闭合马巡游（Closed Knight's Tour）”要求马恰好访问每个方格一次，并在最后一步跳回起点。请问：① 为什么当 \(B\) 为奇数时不存在闭合马巡游？② 用回溯法寻找闭合马巡游时，除了检查方格是否已访问过，还可以用哪些必要条件进行剪枝？ - Ex 6.3: 考虑距离多重集 \(D = \{1, 2, 2, 3, 3, 4, 5, 6, 6, 8\}\)，固定最左点为 \(0\)，能否找到包含点 \(3\) 的解？能否找到包含点 \(5\) 的解？据此说明：固定左端点为 \(0\) 后，收费公路问题的解是否一定唯一？另外，如果搜索过程中从未因后续失败而撤销已放好的点，使用 AVL 树保存距离时，为什么可以在 \(O(n^2\log n)\) 时间内完成重建？

    解答与解析：

    1. 五皇后问题含角点皇后的合法解计数（Exercise 6.1）： 先固定左上角 \((1, 1)\) 放有一个皇后（即 \(x_1 = 1\)）： - 第二行可尝试 \(x_2 = 3\) 或 \(x_2 = 4\)： - 当 \(x_2 = 3\) 时，后续唯一合法填充为 \(x_3 = 5, \ x_4 = 2, \ x_5 = 4\)，得到解 (1, 3, 5, 2, 4)； - 当 \(x_2 = 4\) 时，后续唯一合法填充为 \(x_3 = 2, \ x_4 = 5, \ x_5 = 3\)，得到解 (1, 4, 2, 5, 3)。 注意到这两个解中，其他四个皇后均不在另外三个角点 \((1, 5), (5, 1), (5, 5)\) 上（因为 \((1,1)\) 已经控制了第一行、第一列和主对角线上的 \((5,5)\)，且第五行皇后分别在第 \(4\) 和第 \(3\) 列，故一个合法解至多只能占用 1 个角点，四个角点的解集两两互不相交！）。 将棋盘分别顺时针旋转 \(90^\circ, 180^\circ, 270^\circ\)，每个角点各对应 \(2\) 个解，故总共有 \(4 \times 2 = \mathbf{8}\) 种摆法。（注：五皇后共有 10 种解，另外 2 种是不占任何角点的 (2, 4, 1, 3, 5) 和 (4, 2, 5, 3, 1)）。

    2. 闭合马巡游的黑白染色奇偶性证明与图论剪枝（Exercise 6.2）：

    • ① 为什么奇数边长 \(B\) 不存在闭合马巡游？ 将棋盘按行列坐标之和 \(R + C\) 的奇偶性染成黑白相间的两色（同国际象棋棋盘）。 马每走一步“日”字，其中一个坐标改变 \(\pm 1\)，另一个坐标改变 \(\pm 2\)，因此坐标之和 \(R + C\) 改变了 \(\pm 1\) 或 \(\pm 3\)（均为奇数），这意味着马每跳一步，所在方格的颜色必定发生黑白翻转！ 若存在一条经过全部 \(B^2\) 个方格各一次并回到起点的闭合环路（哈密顿环），则环路必然严格按“黑 \(\to\) 白 \(\to\) 黑 \(\to\) 白 \(\dots\)”交替行进，这要求路径包含的黑格总数与白格总数必须相等，从而总步数 \(B^2\) 必须是偶数！然而当 \(B\) 为奇数时，\(B^2\) 是奇数（黑格与白格数量相差 \(1\)，如 \(5 \times 5\) 棋盘有 \(13\) 黑 \(12\) 白），绝无可能在黑白交替访问全部格子后回到同色起点。
    • ② 回溯剪枝条件设计： 将棋盘建模为无向图 \(G = (V, E)\)：
    • 连通性剪枝：若剩余未访问的方格集合加上起点后构成的导出子图不连通（产生孤立连通分量），则立即剪枝；
    • 度数剪枝（一度/零度死胡同判据）：在搜索中途，若存在某个尚未访问的非起点方格，其在剩余未访问图中关联的可用邻接跳点少于 \(2\) 个（度数为 \(0\) 则无法进入；度数为 \(1\) 且不是立刻跳入它，则未来一旦跳入它就再也无法跳出），则立即剪枝（启发式搜索顺序：优先跳向剩余可用出度最少的方格，即 Warnsdorf 规则，符合“Smaller \(S_i\) first”原则）。

    3. 收费公路重建的非唯一性与无回溯复杂度证明（Exercise 6.3）：

    • 求解与非唯一性说明： 由 \(|D| = 10 = \frac{5 \times 4}{2}\) 知共有 \(n = 5\) 个点，且两端点为 \(x_1 = 0, \ x_5 = 8\)。 执行回溯算法可得包含点 \(3\) 的合法解为 \(X_1 = \{0, 2, 3, 6, 8\}\)。 将点集 \(X_1\) 关于中心点 \(4\) 作左右镜像翻转（即将每个坐标 \(x_i\) 映射为 \(8 - x_i\)），得到新点集 \(X_2 = \{0, 2, 5, 6, 8\}\)（其中包含了点 \(5\)）！由于镜像反射是保距变换，\(X_1\) 与 \(X_2\) 产生的点对距离多重集 \(D\) 完全一致。这说明：即使固定最左端点为 \(0\)，收费公路重建问题的解在镜像翻转意义下也不唯一。
    • 无回溯撤销时的 \(O(n^2\log n)\) 复杂度推导： 若搜索过程中从未发生回溯撤销，则从第 \(1\) 步到第 \(n-2\) 步，每一层最多只调用 \(2\) 次 Check 和 \(1\) 次 Delete。在已经放好 \(k\) 个点时，单次 Check 或 Delete 只需对这 \(k\) 个已放点执行 \(O(k)\) 次 AVL 树查找或删除操作。 将 \(k = 2, 3, \dots, n-1\) 各层的 AVL 树操作次数累加： $$ \text{Total AVL operations} = \sum_{k=2}^{n-1} O(k) = O(n^2) $$ 由于 AVL 树中含有至多 \(\binom{n}{2} = O(n^2)\) 个距离，每次 AVL 树操作耗时 \(O(\log(n^2)) = O(\log n)\)，故总时间复杂度为 \(O(n^2 \log n)\)。
    Exercise 6.4 & 6.5: Alpha-Beta Pruning Bounds & Zermelo's Theorem Proof（博弈树剪枝阈值计算与策梅洛定理证明）

    Problem Statement: - Ex 6.4: 对讲义图 6.9 中的两棵四层二叉树（均按从左到右顺序搜索，第 4 层为叶子，左子树四个叶子依次为 65, 68 和 86, 38；右子树左分支的两个叶子为 70, b [上图] 或 58, b [下图]，右分支内部节点为尚未访问的 \(d\)）： - 上图层次（自顶向下依次为：MIN -> MAX -> MIN -> 叶子，右子树前两个叶子为 70, b）； - 下图层次（自顶向下依次为：MAX -> MIN -> MAX -> 叶子，右子树前两个叶子为 58, b）。 分别求使以节点 \(d\) 为根的整棵子树被剪去的实数 \(b\) 的取值范围。 - Ex 6.5 (策梅洛定理 Zermelo's Theorem): 证明在井字棋（及任何博弈树有限、完全信息、结果为胜/负/平局的确定性双人零和博弈）中，以下三种情况必有且仅有一种成立：(1) 先手玩家有必胜策略；(2) 后手玩家有必胜策略；(3) 双方各自都有保证至少平局（不输）的策略。

    解答与解析：

    1. 博弈树 \(\alpha\text{-}\beta\) 剪枝阈值范围计算（Exercise 6.4，期末必考计算题型）：

    • 上图分析（层序：第 1 层根 MIN \(\to\) 第 2 层 MAX \(\to\) 第 3 层 MIN \(\to\) 第 4 层叶子）：
    • 先算左子树的值：
      • 第 3 层左一 MIN 节点：\(\min(65, 68) = 65\)；
      • 第 3 层左二 MIN 节点：\(\min(86, 38) = 38\)；
      • 第 2 层左 MAX 节点：\(\max(65, 38) = \mathbf{65}\)。
      • 由此，第 1 层根节点（MIN）获得了上界 \(\beta = 65\)（根最终值 \(\le 65\)）。
    • 再看右子树何时剪掉 \(d\)：
      • 右子树根是第 2 层右 MAX 节点，其左孩子是第 3 层 MIN 节点（叶子为 \(70\) 和 \(b\)），故该第 3 层 MIN 节点算出的值为 \(v = \min(70, b)\)。
      • 第 2 层右 MAX 节点拿到了第一个孩子的值 \(v = \min(70, b)\)，故该 MAX 节点的最终值必 \(\ge \min(70, b)\)。
      • 要在访问其右孩子 \(d\) 之前触发 \(\beta\) 剪枝，只需该下界已经大于等于根 MIN 节点的上界 \(\beta = 65\)： $$ \min(70, b) \ge 65 \quad (\text{因 } 70 \ge 65 \text{ 已成立}) \implies \mathbf{b \ge 65} $$
    • 下图分析（层序：第 1 层根 MAX \(\to\) 第 2 层 MIN \(\to\) 第 3 层 MAX \(\to\) 第 4 层叶子）：
    • 先算左子树的值：
      • 第 3 层左一 MAX 节点：\(\max(65, 68) = 68\)；
      • 第 3 层左二 MAX 节点：\(\max(86, 38) = 86\)；
      • 第 2 层左 MIN 节点：\(\min(68, 86) = \mathbf{68}\)。
      • 由此，第 1 层根节点（MAX）获得了保底值 \(\alpha = 68\)（根最终值 \(\ge 68\)）。
    • 再看右子树何时剪掉 \(d\)：
      • 右子树根是第 2 层右 MIN 节点，其左孩子是第 3 层 MAX 节点（叶子为 \(58\) 和 \(b\)），故该第 3 层 MAX 节点算出的值为 \(v = \max(58, b)\)。
      • 第 2 层右 MIN 节点拿到了第一个孩子的值 \(v = \max(58, b)\)，故该 MIN 节点的最终值必 \(\le \max(58, b)\)。
      • 要在访问其右孩子 \(d\) 之前触发 \(\alpha\) 剪枝，只需该上界已经小于等于根 MAX 节点的下界 \(\alpha = 68\)： $$ \max(58, b) \le 68 \quad (\text{因 } 58 \le 68 \text{ 已成立}) \implies \mathbf{b \le 68} $$

    2. 策梅洛定理（Zermelo's Theorem）的 Minimax 归纳证明（Exercise 6.5）： 将先手（MAX 玩家）获胜、平局、后手（MIN 玩家）获胜的终局叶节点效用分别赋值为 \(+1, \ 0, \ -1\)。由于博弈树有限，可自底向上对每个节点计算出唯一的确定性 Minimax 值 \(V(\text{node}) \in \{+1, 0, -1\}\)。考察初始空棋盘根节点的值 \(V(\text{root})\)：

    1. 若 \(V(\text{root}) = +1\)（先手必胜）： 在任何轮到先手的 MAX 节点（值为 \(+1\)），其孩子中至少有一个值为 \(+1\)，先手只需选择进入该孩子；在任何轮到后手的 MIN 节点（值为 \(+1\)），由于最小值都是 \(+1\)，说明其所有孩子的值全为 \(+1\)，后手无论怎么走都只能进入值为 \(+1\) 的子节点。如此走到终局叶子，值必为 \(+1\)，即先手有必胜策略。
    2. 若 \(V(\text{root}) = -1\)（后手必胜）： 完全对称地，后手在 MIN 节点总能选择值为 \(-1\) 的孩子，而先手在值为 \(-1\) 的 MAX 节点下所有孩子均为 \(-1\)，最终必到达 \(-1\) 的叶子，即后手有必胜策略。
    3. 若 \(V(\text{root}) = 0\)（双方均有保平局不输策略）： 先手在 MAX 节点总是选择值 \(\ge 0\) 的孩子，可保证终局值 \(\ge 0\)（绝不会输）；同时后手在 MIN 节点总是选择值 \(\le 0\) 的孩子，可保证终局值 \(\le 0\)（也绝不会输）。双方均采取该策略时必以 \(0\)（平局）告终。 由于根节点的 Minimax 值只能唯一地取 \(+1, -1, 0\) 之一（且一方必胜与另一方保不输显然互斥），故三种情况必居其一且互斥，证毕。
