## 1 贪心算法基本原理与活动选择问题 (Greedy Strategy & Activity Selection)

### 1.1 最优化问题与贪心设计三要素

在**最优化问题**（Optimization Problems）中，满足问题给定约束条件（Constraints）的解称为**可行解**（Feasible solutions），使目标函数（Optimization function）取得最优值（最大或最小）的可行解称为**最优解**（Optimal solution）。

**贪心法（The Greedy Method）的核心思想**：
分阶段逐步构建解。在每一个阶段，根据某种**贪心准则**（Greedy criterion）做出在当前看来最好的局部最优决策（Local optimum）；**一旦做出某步决策，在后续阶段中绝不撤回或更改（No backtracking）**，因此每一步决策都必须保证可行性。

- **适用前提**：贪心算法能够求得全局精确最优解，当且仅当问题的**局部最优选择总是等于全局最优选择**（Local optimum $=$ Global optimum）。当无法保证精确最优时，贪心法常作为高效的启发式或近似算法（Approximation heuristics）。
- **设计并证明贪心算法的三个核心步骤（Elements of the Greedy Strategy，PPT Slide 9）**：
  1. **问题转化（One choice + One subproblem）**：将最优化问题转化为“做出一次贪心选择后，只留下**唯一一个**待求解的子问题”（对比动态规划：DP 做出选择后通常可能依赖多个子问题）；
  2. **证明贪心选择性质（Greedy-choice Property）**：证明原问题**总是存在一个包含第一步贪心选择的最优解**（因此做出该贪心选择总是安全的 Safe；最常用的证明工具是**交换参数法 Exchange Argument**）；
  3. **证明最优子结构性质（Optimal Substructure）**：证明在做出贪心选择后，将剩余子问题的最优解与该贪心选择直接组合，即可得到原问题的最优解（通常用反证法证明）。

> *"Beneath every greedy algorithm, there is almost always a more cumbersome dynamic-programming solution."*（在每一个贪心算法背后，几乎总有一个更繁琐的动态规划解法）。

### 1.2 活动选择问题 (Activity Selection Problem)

**1. 问题描述与两种动态规划解法对比（PPT Slides 4–8 & 讲义 §9.1）**

给定 $n$ 个申请使用同一间教室的活动集合 $S = \{a_1, a_2, \dots, a_n\}$，每个活动 $a_i$ 占用半开时间区间 $[s_i, f_i)$。若两个活动满足 **$s_i \ge f_j$ 或 $s_j \ge f_i$**（时间区间不重叠），则称它们是**兼容的**（Compatible）。求包含活动数量最多的相互兼容活动子集。（假设活动已按结束时间递增排序：$f_1 \le f_2 \le \dots \le f_n$）。

在尝试贪心之前，先看两种动态规划思路：
- **DP 思路一（双端区间 DP）**：定义 $S_{ij}$ 为在 $a_i$ 结束后且在 $a_j$ 开始前进行的活动子集，状态 $c_{ij}$ 为 $S_{ij}$ 中的最大兼容活动数。若在 $S_{ij}$ 中选了 $a_k$，问题分裂为 $S_{ik}$ 和 $S_{kj}$ 两个子问题：
  $$c_{ij} = \max_{a_k \in S_{ij}} \big\{ c_{ik} + c_{kj} + 1 \big\} \qquad (\text{时间复杂度 } O(N^2) \text{ 至 } O(N^3))$$
- **DP 思路二（一维前缀 DP，Slide 8）**：定义 $c_{1, j}$ 为前 $j$ 个活动 $\{a_1, \dots, a_j\}$ 中的最大兼容活动数。考察最后一个活动 $a_j$ 选或不选：若选 $a_j$，则前一个活动只能从在 $s_j$ 之前（或恰好在 $s_j$）结束的活动里选，记满足 $f_k \le s_j$ 的最大下标记为 $k(j)$（可用二分查找在 $O(\log N)$ 内找到）：
  $$c_{1, j} = \begin{cases} 1, & \text{if } j = 1, \\ \max\big\{ c_{1, j-1}, \ \ c_{1, k(j)} + 1 \big\}, & \text{if } j > 1. \end{cases} \qquad (\text{时间复杂度 } O(N \log N))$$

**2. 四种贪心规则的碰撞与三个经典反例（PPT Slides 5–6 & 板书 `W6` Pages 2–3）**

为了进一步将过程简化为无需回看历史子问题的纯贪心，每次在不与已选活动冲突的剩余活动里挑选一个活动，共有四种直观的贪心规则，其中**前三种均错误**，只有第四种正确：

| 贪心规则候选 | 是否最优 | 构造反例与物理分析（对照讲义图 9.1 & 板书 `W6`） |
| :--- | :---: | :--- |
| **Rule 1: 最早开始时间**<br>（Smallest start time, $\min s_i$） | **否 ($\times$)** | **反例**：设活动 1 为 $[0, 10)$，活动 2、3 为 $[1, 2), [2, 3)$。<br>最早开始的 $[0, 10)$ 持续时间极长，霸占整段教室，导致只能选 1 个（最优可选 2 个）。 |
| **Rule 2: 最短持续时间**<br>（Shortest duration, $\min (f_i - s_i)$） | **否 ($\times$)** | **反例**：设三个活动为 $[0, 5), \ [4, 7), \ [6, 10)$。<br>最短的活动 $[4, 7)$（长 $3$）恰好卡在左右两个兼容活动 $[0, 5)$ 和 $[6, 10)$ 的交界处，选它只能得 1 个（最优可选左右 2 个）。 |
| **Rule 3: 最少冲突次数**<br>（Fewest conflicts with others） | **否 ($\times$)** | **反例**：设顶层主链有 4 个互不重叠的活动 $a=[0,2), b=[3,5), c=[6,8), d=[9,11)$（最优解选这 4 个）。<br>在 $a, b$ 交界处放 3 个重叠区间 $[1,4)$，在 $c, d$ 交界处也放 3 个重叠区间 $[7,10)$，而在 $b, c$ 交界处只放 1 个区间 $x=[4,7)$。<br>此时 $x$ 仅与 $b, c$ 冲突（冲突数 $=2$，全场最少！其余活动冲突数均 $\ge 3$），但一旦先选了 $x$，$b$ 和 $c$ 全废，最多只能选 $\{a, x, d\}$ 共 3 个！ |
| **Rule 4: 最早结束时间**<br>（Earliest finish time, $\min f_i$） | **是 ($\checkmark$)** | **核心直觉**：所选活动结束得越早，教室就能越早腾空出来（*Resource becomes free as soon as possible*），留给后续待安排活动的可用时间窗口 $[f_i, +\infty)$ 就最大化！（对称地，从后往前每次选**最晚开始时间 $\max s_i$** 也同样正确）。 |

```c
/* 活动选择贪心算法 (Activity Selection by Earliest Finish Time) */
/* 时间复杂度：排序 O(n log n) + 线性扫描 O(n) = O(n log n) */
List ActivitySelection(Activity S[], int n) {
    Sort S[1..n] in non-decreasing order of finish time: f_1 <= f_2 <= ... <= f_n;
    List A = EmptyList();
    int last_finish = 0;
    for (int i = 1; i <= n; i++) {
        if (S[i].s >= last_finish) { /* 与上一个已选活动兼容 */
            Append(A, S[i]);
            last_finish = S[i].f;
        }
    }
    return A;
}
```

**3. 最早结束时间贪心策略的两种严格正确性证明**

<details markdown="1">
<summary>点击展开：证明方法一（PPT 交换参数法）与证明方法二（老师板书下标归纳领先法）</summary>

**方法一：交换参数法（Exchange Argument，PPT Slide 7 & 讲义定理 9.1）**
- **定理**：对于任意非空子问题 $S_k$，令 $a_m$ 是 $S_k$ 中结束时间最早的活动（$f_m = \min_{a_i \in S_k} f_i$），则 $a_m$ 必包含在 $S_k$ 的某个最大兼容活动子集中。
- **证明**：任取 $S_k$ 的一个最优解集合 $A_k$，设 $a_{ef}$ 是 $A_k$ 中结束时间最早的活动。
  - 若 $a_{ef} = a_m$，则结论已成立；
  - 若 $a_{ef} \neq a_m$，构造新集合 $A_k' = (A_k \setminus \{a_{ef}\}) \cup \{a_m\}$（即用贪心选择的 $a_m$ 替换掉 $A_k$ 中的第一个活动 $a_{ef}$）。
  因为 $a_m$ 是整个 $S_k$ 中结束最早的，故必有 **$f_m \le f_{ef}$**。而 $A_k$ 中除 $a_{ef}$ 以外的所有其他活动都是在 $f_{ef}$ 之后才开始的（$\ge f_{ef} \ge f_m$），因此将 $a_{ef}$ 替换为结束更早的 $a_m$ 后，$A_k'$ 中的所有活动依然两两兼容！且 $\vert{}A_k'\vert{} = \vert{}A_k\vert{}$，故 $A_k'$ 也是 $S_k$ 的一个包含 $a_m$ 的最优解。

---

**方法二：下标归纳“步步领先”证法（"Greedy Stays Ahead"，老师手写板书 `W6` Pages 3–4）**
设贪心算法选出的活动序列（按时间顺序）为 $A = (i_1, i_2, \dots, i_k)$。
假设存在另一个兼容活动序列 $A^* = (j_1, j_2, \dots, j_{k^*})$ 且满足 $k^* > k$（反证假设）。
我们通过对下标 $t \ (1 \le t \le k)$ 作数学归纳，证明贪心算法选出的第 $t$ 个活动的结束时间永远不晚于 $A^*$ 中第 $t$ 个活动的结束时间：

$$f_{i_t} \le f_{j_t}, \qquad \forall t = 1, 2, \dots, k$$

- **当 $t = 1$ 时**：因为贪心算法第 1 步选的 $i_1$ 是全场结束最早的活动，故显然有 $f_{i_1} \le f_{j_1}$；
- **由 $t - 1$ 推 $t$**：假设 $f_{i_{t-1}} \le f_{j_{t-1}}$ 成立。由于 $A^*$ 内部兼容，其第 $t$ 个活动满足 $s_{j_t} \ge f_{j_{t-1}} \ge f_{i_{t-1}}$。这说明**活动 $j_t$ 与贪心已选的 $i_{t-1}$ 也是兼容的**（即 $j_t$ 在贪心第 $t$ 步的候选池中）！而贪心第 $t$ 步在所有兼容候选者中挑了结束最早的 $i_t$，故必有 $f_{i_t} \le f_{j_t}$，归纳完成！
- **导出矛盾**：当 $t = k$ 时，有 $f_{i_k} \le f_{j_k}$。如果 $k^* > k$，则 $A^*$ 中还存在第 $k + 1$ 个活动 $j_{k+1}$，它满足 $s_{j_{k+1}} \ge f_{j_k} \ge f_{i_k}$，这意味着在 $i_k$ 结束后，候选池中明明还有兼容的活动 $j_{k+1}$ 可选，贪心算法绝不可能在选完 $i_k$ 后就停止！矛盾，故必有 $k \ge k^*$，贪心解全局最优。

</details>

**4. 两大重要变体：加权活动选择 vs. 教室分配问题**

- **变体一：加权活动选择问题（Weighted Activity Selection，PPT Slide 8 & 讲义例 9.3）**：
  若每个活动 $a_j$ 具有权重/收益 $w_j > 0$，目标是最大化所选兼容活动的总权重。
  - **Q1: 贪心法（最早结束时间）还正确吗？** **不正确**！（反例：$[0, 2)$ 权为 $1$，$[1, 3)$ 权为 $100$，贪心选了前者得 $1$，漏掉 $100$）。
  - **Q2: 动态规划解法还正确吗？** **完全正确**！只需将一维 DP 递推式中的 $+1$ 替换为 $+w_j$，即可在 $O(N\log N)$ 时间内精确求解：
    $$c_{1, j} = \max\big\{ c_{1, j-1}, \ \ c_{1, k(j)} + w_j \big\}$$
- **变体二：教室分配 / 区间图着色问题（Interval Partitioning，讲义例 9.4）**：
  若要求**所有 $n$ 个活动都必须举办**，互不冲突的活动可共用同一间教室，求**最少需要开设多少间教室**？
  - **贪心策略**：**将所有活动按开始时间 $s_i$ 从早到晚递增排序**（注意：此处必须按**开始时间**排序，若按结束时间排序则错误，见习题 9.3(2)！）。依次扫描每个活动：若当前存在某间已开设教室的最后一个活动已经结束（$\le s_i$），则直接复用该教室；若所有已开教室都在忙碌中，则新开一间教室。
  - **正确性（上下界相等）**：设算法最终开设了 $d$ 间教室。由于第 $d$ 间教室是在前 $d-1$ 间教室全都与当前活动 $a_i$ 冲突（即它们的结束时间都 $> s_i$，而开始时间都 $\le s_i$）时才被迫新开的，这说明在时刻 $s_i^+$ **确实有 $d$ 个活动在同时进行**！任何合法方案至少需要 $d$ 间教室，故贪心解必然达到理论下界。用最小堆维护各教室的结束时间，总耗时为 $O(n\log n)$。

## 2 哈夫曼编码与前缀码树 (Huffman Codes & Prefix-Free Trees)

### 2.1 变长前缀码与编码二叉树表示

假设文本由字符集 $\Sigma$（大小为 $C = |\Sigma|$）中的字符组成，每个字符 $c_i$ 在文本中出现的频数（Frequency）为 $f_i$。
- **定长编码（Fixed-length code）**：每个字符统一用 $\lceil\log_2 C\rceil$ 个比特表示（如 4 个字符 `a=00, u=01, x=10, z=11`）。当各字符出现频率极不均匀时，定长编码浪费了大量空间。
- **变长编码与无前缀约束（Prefix-Free Code）**：为高频字符分配短码字，为低频字符分配长码字。但为了保证编码后的比特流能够**无歧义地唯一解码（Decode unambiguously）**，必须要求：**没有任何一个字符的码字是另一个字符码字的前缀（Prefix）**！这样的编码称为**前缀码**（Prefix code / Prefix-free code）。
- **编码二叉树表示（`{0, 1}`-Tree / Trie，PPT Slide 11 & 板书 `W6` Page 5）**：
  在二叉树中，左分支标 `0`、右分支标 `1`。**一种编码是无歧义的前缀码，当且仅当所有字符都只放置在二叉树的叶节点（Leaf nodes）上**（没有任何字符位于内部节点上）！
  - 此外，在**最优前缀码树**中，每个内部节点都**必须恰好有两个孩子**（即为满二叉树 Full binary tree；若某内部节点只有一个孩子，直接删去该内部节点让孩子顶替，可使其下所有字符码长减 $1$，严格更优）。因此，**含 $C$ 个字符（$C$ 个叶子）的哈夫曼树必定恰好有 $C - 1$ 个内部节点，总结点数恒为 $2C - 1$（奇数）**！

设字符 $c_i$ 所在叶节点的深度（即码字比特长度）为 $d_i$，则整篇文本编码后的**总比特长度（Total code cost / 带权外部路径长度 WPL）**为：

$$B(T) = \text{Cost}(T) = \sum_{i=1}^C f_i \cdot d_i$$

### 2.2 哈夫曼算法 (Huffman's Algorithm, 1952) 与老师板书增量视角

**1. 老师手写板书专属视角：逐层合并增量分解（`ADS26W6.pdf` Page 6）**

为什么每次合并频数最小的两个节点能使总代价 $\sum f_i d_i$ 最小？老师在板书中给出了极其直观的代数分解：
- 初始时，每个字符都是独立的单节点树（深度均为 $0$），初始总代价为 $\text{AD}(0) = 0$。
- 每当我们把两棵子树 $T_1, T_2$ 合并挂到一个新父节点下方时，$T_1$ 和 $T_2$ 中**所有叶节点的深度都同时增加了 $1$**！因此，这一次合并操作使目标函数 $\sum f_i d_i$ 产生的**代价增量（Increment）**恰好等于这两棵子树中所有叶子的频数之和：
  $$
  \Delta = f(T_1) + f(T_2)
  $$
- 整个构树过程共需执行 $C - 1$ 次合并，最终树的总代价恒等于这 $C - 1$ 次合并各自的增量之和（等价于**所有非根内部节点的权重之和**）：
  $$
  B(T) = \sum_{i=1}^C f_i d_i = \sum_{k=1}^{C-1} \Delta_k
  $$
  因此，**哈夫曼准则（Huffman's Criterion）的本质就是：在每一步合并中，贪心地挑选当前权重最小的两棵树进行合并，从而使当前步的目标函数增量 $\Delta_k$ 最小**！

**2. 哈夫曼算法伪代码实现（耗时 $T = O(C \log C)$，PPT Slide 12）**

```c
/* 使用最小堆 (Min-Heap) 构建哈夫曼树，总时间复杂度 T = O(C log C) */
void Huffman(PriorityQueue heap[], int C) {
    /* 将 C 个字符看作 C 棵单节点二叉树，初始化建立最小堆 (BuildHeap 耗时 O(C)) */
    consider the C characters as C single node binary trees,
    and initialize them into a min heap;

    for (i = 1; i < C; i++) { /* 共合并 C - 1 次 */
        create a new internal node;
        /* Greedy choice: 连续两次取出当前频数最小的两棵树 */
        delete root from min heap and attach it to left_child of node;
        delete root from min heap and attach it to right_child of node;
        weight of node = sum of weights of its children;
        insert node into min heap;
    }
}
```

**课堂 7 字符实例（PPT Slide 13）**：
给定字符频数：`nl(1), s(3), t(4), a(10), i(12), sp(13), e(15)`（总频数 $58$）：
1. 合并 `nl(1)` 与 `s(3)` $\to$ 内部节点 `(4)`；
2. 合并 `t(4)` 与 `(4)` $\to$ 内部节点 `(8)`；
3. 合并 `(8)` 与 `a(10)` $\to$ 内部节点 `(18)`；
4. 合并最小的 `i(12)` 与 `sp(13)` $\to$ 内部节点 **`(25)`**；
5. 合并最小的 `e(15)` 与 `(18)` $\to$ 内部节点 **`(33)`**；
6. 最后合并 `(25)` 与 `(33)` $\to$ 根节点 **`(58)`**。
编码结果：`i: 00 (2位)`, `sp: 01 (2位)`, `e: 10 (2位)`, `a: 111 (3位)`, `t: 1100 (4位)`, `nl: 11010 (5位)`, `s: 11011 (5位)`。
总编码代价：$\text{Cost} = 10\times 3 + 15\times 2 + 12\times 2 + 3\times 5 + 4\times 4 + 13\times 2 + 1\times 5 = \mathbf{146}$（注：等于所有内部节点权值和 $4 + 8 + 18 + 25 + 33 + 58 = 146$！）。

### 2.3 哈夫曼算法最优性的两条引理证明与信息熵界

<details markdown="1">
<summary>点击展开：贪心选择引理、最优子结构引理（PPT Slides 14–15 & 板书 W6）与香农熵界证明</summary>

**引理 2.1（贪心选择性质 Greedy-Choice Property）**：
设字母表 $C$ 中频数最小的两个字符为 $x$ 和 $y$（满足 $f_x \le f_y \le f_c, \ \forall c \in C$）。则必存在一棵关于 $C$ 的最优前缀码树，使得 **$x$ 和 $y$ 是位于最深层的兄弟叶节点**（即它们的码字长度相等且仅最后一位比特不同）。

- **证明（交换参数法）**：任取一棵最优前缀码树 $T$，由于 $T$ 是满二叉树，其最大深度处必存在一对兄弟叶节点，记为 $a$ 和 $b$（不妨设 $f_a \le f_b$）。
  因为 $x, y$ 是全集频数最小的两个字符，故必有 **$f_x \le f_a$ 且 $f_y \le f_b$**；同时因为 $a, b$ 位于全树最深层，故深度满足 **$d_T(a) \ge d_T(x)$ 且 $d_T(b) \ge d_T(y)$**。
  在树 $T$ 中，先交换 $a$ 和 $x$ 的位置得到树 $T'$，再交换 $b$ 和 $y$ 的位置得到树 $T''$。计算总代价的变化：
  $$
  \begin{aligned}
  \text{Cost}(T) - \text{Cost}(T'') &= \big[f_x d_T(x) + f_a d_T(a) - f_x d_T(a) - f_a d_T(x)\big] + \big[f_y d_T(y) + f_b d_T(b) - f_y d_T(b) - f_b d_T(y)\big] \\
  &= \underbrace{(f_a - f_x)}_{\ge\,0}\underbrace{\big(d_T(a) - d_T(x)\big)}_{\ge\,0} + \underbrace{(f_b - f_y)}_{\ge\,0}\underbrace{\big(d_T(b) - d_T(y)\big)}_{\ge\,0} \ge 0
  \end{aligned}
  $$
  因此 $\text{Cost}(T'') \le \text{Cost}(T)$，又因 $T$ 已是最优树，故 $\text{Cost}(T'') = \text{Cost}(T)$，即 $T''$ 是一棵把 $x, y$ 作为最深兄弟叶子的最优树！

---

**引理 2.2（最优子结构性质 Optimal Substructure）**：
将最小频数字符 $x, y$ 合并为一个频数为 $f_z = f_x + f_y$ 的新字符 $z$，构成缩减字母表 $C' = (C \setminus \{x, y\}) \cup \{z\}$。若 $T'$ 是 $C'$ 的最优前缀码树，则将 $T'$ 中的叶节点 $z$ 替换为以 $x, y$ 为左右孩子的内部节点后得到的树 $T$，必是原字母表 $C$ 的最优前缀码树。

- **证明（反证法）**：由于在 $T$ 中 $d_T(x) = d_T(y) = d_{T'}(z) + 1$，故 $f_x d_T(x) + f_y d_T(y) = (f_x + f_y)(d_{T'}(z) + 1) = f_z d_{T'}(z) + (f_x + f_y)$，从而两树总代价满足固定差值关系：
  $$
  \text{Cost}(T) = \text{Cost}(T') + f_x + f_y
  $$
  若 $T$ 不是 $C$ 的最优树，则由引理 2.1 知存在另一棵将 $x, y$ 作为兄弟叶子的最优树 $T^*$ 满足 $\text{Cost}(T^*) < \text{Cost}(T)$。将 $T^*$ 中的 $x, y$ 收缩为叶子 $z$ 得到 $C'$ 的编码树 $T^{*\prime}$，其代价为 $\text{Cost}(T^{*\prime}) = \text{Cost}(T^*) - (f_x + f_y) < \text{Cost}(T) - (f_x + f_y) = \text{Cost}(T')$，这与 $T'$ 是 $C'$ 的最优树矛盾！

---

**讲义补充（§9.4.2 & §9.6）：Kraft 不等式与香农信息熵上下界**
- **Kraft 不等式**：一棵二叉树上存在码长分别为 $l_1, l_2, \dots, l_m$ 的前缀码，当且仅当 $\sum_{i=1}^m 2^{-l_i} \le 1$。
- **香农信息熵（Shannon Entropy）与平均码长界**：设各字符出现概率为 $p_i > 0 \ (\sum p_i = 1)$，信息熵定义为 $H(X) = -\sum_{i=1}^m p_i \log_2 p_i$。利用不等式 $\ln t \le t - 1$ 与 Kraft 不等式可严格证得：任何二进制前缀码的平均码长 $L = \sum p_i l_i$ 均不小于信息熵 $H(X)$（等号成立当且仅当对所有 $i$ 有 $p_i = 2^{-l_i}$）；同时取香农码 $l_i = \lceil -\log_2 p_i \rceil$ 可证得哈夫曼编码的平均码长 $L_H$ 严格满足：
  $$
  H(X) \le L_H < H(X) + 1
  $$

## 3 老师板书与讲义核心专题：任务调度、Belady 离线缓存与拟阵理论

### 3.1 单机任务调度三大模型汇总 (Single-Machine Scheduling)

在老师手写板书（`ADS26W6.pdf` Pages 1–2）与讲义（§9.2）中，系统对比了单台机器连续执行 $n$ 个任务的三大经典贪心调度模型（均通过**相邻交换参数法 Adjacent Exchange Argument** 证明最优性）：

| 调度问题模型 | 任务输入参数 | 优化目标函数 | 最优贪心排序准则与相邻交换证明核心 |
| :--- | :--- | :--- | :--- |
| **1. 最小化完成时间和**<br>（板书 `W6` Pages 1–2） | 处理时间 $p_j > 0$<br>（无权重） | $\min \displaystyle\sum_{j=1}^n C_j(\sigma)$<br>$= \sum_{i=1}^n p_{\sigma^{-1}(i)}(n - i + 1)$ | **最短处理时间优先（SPT，板书记为 LPT: Least Processing Time first）**：<br>按 **$p_j$ 从小到大升序排列**。若相邻两任务 $j_1$ 在 $j_2$ 前但 $p_{j_1} > p_{j_2}$，交换它们后目标函数变化量为 $(p_{j_2} - p_{j_1}) < 0$，严格更优！ |
| **2. 最小化加权完成时间和**<br>（讲义定理 9.5 & 9.6） | 处理时间 $l_i > 0$<br>重要度权重 $w_i > 0$ | $\min \displaystyle\sum_{i=1}^n w_i C_i(\sigma)$ | **按权重与耗时之比 $\dfrac{w_i}{l_i}$ 从大到小降序排列**（注意：按差值 $w_i - l_i$ 排序错误！）：<br>交换相邻的 $j, i$ 前后代价差为 $t_1 - t_2 = w_i l_j - w_j l_i \ge 0 \iff \frac{w_i}{l_i} \ge \frac{w_j}{l_j}$。 |
| **3. 最小化最大延迟**<br>（Minimize Max Lateness，讲义例 9.7） | 处理时间 $t_j > 0$<br>截止时间 $d_j$ | $\min \displaystyle\max_{1 \le j \le n} L_j$<br>（其中 $L_j = \max\{0, C_j - d_j\}$） | **最早截止时间优先（EDD: Earliest Deadline First）**：<br>按**截止时间 $d_j$ 从小到大升序排列**（与处理时间 $t_j$ 无关！）：<br>若相邻 $i$ 在 $j$ 前且 $d_i > d_j$（逆序对），交换后 $\max\{0, C_i^{\text{new}} - d_i\} \le \max\{0, C_j^{\text{old}} - d_j\}$，最大延迟绝不增加！ |

### 3.2 离线最优缓存替换：Belady 最远将来算法 (Farthest-in-Future — 板书 `W6` Pages 10–13)

**问题描述**：缓存（Cache）容量为 $k$，初始存放着 $k$ 个数据页。现已知未来完整的长度为 $m$ 的页面请求序列 $d_1, d_2, \dots, d_m$。当请求的页面不在缓存中时发生**缺页（Cache miss）**，必须将该页调入缓存并从当前缓存中驱逐（Evict / Replace）一个页面。求使全程总缺页次数最少的离线替换策略。

- **常见在线启发式策略（非最优）**：
  - **LRU（Least Recently Used）**：替换最近一次访问时间最早（最久未使用）的页面；
  - **LFU（Least Frequently Used）**：替换过去访问频次最少的页面。
- **离线全局最优策略：Belady 最远将来算法（Farthest-in-Future, FF, Belady 1966）**：
  当发生缺页需要替换时，**选择当前缓存中“下一次被请求的时间在未来最晚（或未来不再被请求）”的那一页将其替换出去**！

<details markdown="1">
<summary>点击展开：老师手写板书（ADS26W6 Pages 11–13）Belady 最远将来算法最优性的严格交换证明</summary>

1. **引理（精简调度 Reduced Schedule）**：任何提前调入页面的方案都可以转化为“**仅当某页面被请求且发生缺页时才将其调入**”的精简方案（Reduced solution），且缺页次数不会增加。以下只需在精简方案之间比较。
2. **定理证明（交换参数法 Exchange Argument）**：
   设 $FF$ 为最远将来贪心方案，任取一个最优精简方案 $OPT$。假设 $OPT$ 与 $FF$ 在前 $j - 1$ 步完全一致，在第 $j$ 步请求页面 $d$ 发生缺页时首次出现分歧：
   - 设分歧前两者的共同缓存内容包含 $\{b, c, \dots\}$；
   - 在第 $j$ 步，$FF$ 选择驱逐了页面 **$c$**（换入 $d$，缓存变为 $\{b, d, \dots\}$），而 $OPT$ 选择驱逐了页面 **$b$**（换入 $d$，缓存变为 $\{c, d, \dots\}$）。
   - 根据 $FF$ 的最远将来规则，既然 $FF$ 淘汰了 $c$ 而不是 $b$，说明在未来的请求序列中，**页面 $b$ 必定比页面 $c$ 更早被再次请求**！
   我们构造一个新的最优方案 $OPT'$：令 $OPT'$ 在第 $j$ 步模仿 $FF$ **也驱逐 $c$（保留 $b$）**，此后 $OPT'$ 的缓存比 $OPT$ 多一个 $b$、少一个 $c$。考察在 $b$ 被请求或 $c$ 被淘汰之前的后续步骤（此时 $c$ 尚未被请求！），分三种情况使 $OPT'$ 与 $OPT$ 的缓存重新完全同步且缺页数不增加（板书 Pages 12–13）：
   - **Case 1（在请求 $b$ 之前，遇到了请求某页 $e \neq b, c$ 导致 $OPT$ 缺页，且 $OPT$ 正好决定驱逐 $c$ 来换入 $e$）**：
     此时直接让 $OPT'$ **驱逐 $b$ 来换入 $e$**！两者的缓存瞬间恢复完全相同（都变成 $\{e, d, \dots\}$），且缺页次数一模一样！
   - **Case 2（在请求 $b$ 之前，遇到了请求某页 $e \neq b, c$ 导致 $OPT$ 缺页，但 $OPT$ 驱逐了另一个公共页 $f \neq c$）**：
     此时让 $OPT'$ 也同样驱逐 $f$ 换入 $e$，继续保持“$OPT'$ 比 $OPT$ 多 $b$ 少 $c$”的不变量向后走。
   - **Case 3（一路走到了请求页面 $b$ 的时刻！）**：
     因为在 $b$ 被请求前 $c$ 从未被请求过，所以在这一刻：**$OPT'$ 的缓存里有 $b$（直接命中 Hit，不缺页！），而 $OPT$ 的缓存里没有 $b$（发生一次缺页 Miss！）**。
     $OPT$ 因缺页必须调入 $b$ 并驱逐某页：
     - 若 $OPT$ 恰好驱逐了 $c$ 换入 $b$，则 $OPT$ 与 $OPT'$ 瞬间完全一致；
     - 若 $OPT$ 驱逐了某公共页 $f$ 换入 $b$，我们就在这一步让 $OPT'$ **驱逐 $f$ 并把 $c$ 调入**（虽然后面可将此次对 $c$ 的调入推迟到 $c$ 真正被请求时以保持精简性），此时 $OPT'$ 多花的一次调入恰好抵消了刚才在 $b$ 上省下的一次命中，两者缓存完全恢复一致且总缺页次数满足 $\text{Miss}(OPT') \le \text{Miss}(OPT)$！
   对后续分歧归纳重复上述调整，即证 $FF$ 是全局最优离线缓存算法。（注：用最大堆维护缓存中各页的下次访问下标，总时间复杂度为 $O(m \log k)$）。

</details>

### 3.3 讲义拓展：拟阵理论 (Matroids) 与市场匹配算法 (TTC & Gale-Shapley)

<details markdown="1">
<summary>点击展开：拟阵加权贪心（单位时长惩罚调度）与 TTC 房屋交换 / Gale-Shapley 稳定匹配（讲义 §9.3 & §9.5）</summary>

**1. 拟阵（Matroid）与单位时长带截止时间任务的最小惩罚调度（讲义 §9.3.2 & §9.3.3）**

- **拟阵定义**：序偶 $M = (E, \mathcal{I})$ 称为拟阵，若有限集 $E$ 的非空子集族 $\mathcal{I}$（称为独立集 Independent sets）满足：
  1. **遗传性（Hereditary property）**：若 $B \in \mathcal{I}$ 且 $A \subseteq B$，则 $A \in \mathcal{I}$（从而 $\emptyset \in \mathcal{I}$）；
  2. **交换性 / 增广性质（Exchange / Augmentation property）**：若 $A, B \in \mathcal{I}$ 且 $|A| < |B|$，则必存在元素 $e \in B \setminus A$ 使得 $A \cup \{e\} \in \mathcal{I}$。
- **拟阵贪心定理**：对于任意赋有非负元素权重 $w(e) \ge 0$ 的拟阵 $(E, \mathcal{I})$，将元素按权重从大到小降序排列，依次扫描并将保持独立性的元素加入集合，所得集合必是总权重最大的独立集！（例如无向图的无环边集构成**图拟阵 Graphic matroid**，对应的贪心算法即 Kruskal 最小生成树算法）。
- **应用：单位时长任务的最小延时惩罚调度（例 9.8 & §9.3.3）**：
  给定 $n$ 个均只需 $1$ 单位时间的任务，第 $i$ 个任务的截止时间为正整数 $d_i$，若未在 $d_i$ 前完成则罚款 $w_i \ge 0$。求使总罚款最小的调度顺序（等价于选出总罚款 $\sum w_i$ 最大的能够全部按时完成的任务子集）。
  - **独立集判据**：任务子集 $A \subseteq E$ 能够全部按时完成（按 $d_i$ 递增执行），当且仅当对任意时刻 $t \in \{1, 2, \dots, n\}$，集合 $A$ 中截止时间 $\le t$ 的任务个数满足 **$N_t(A) \equiv |\{i \in A : d_i \le t\}| \le t$**！
  - $(E, \mathcal{I})$ 构成拟阵，因此**贪心算法**：直接将所有任务按**惩罚 $w_i$ 从大到小降序排列**，依次检查每个任务：若加入后仍满足所有 $N_t(A) \le t$（即尽量将其安排在不超过 $d_i$ 的最晚空闲时间槽位上），则选入按时集合 $A$；否则将其丢入超时受罚集合 $R$（放在最后任意时间执行）。时间复杂度为 $O(n^2)$（用并查集优化找空闲槽位可达 $O(n\log n)$）。

---

**2. 算法博弈论中的两大经典匹配算法（讲义 §9.5，2012 诺贝尔经济学奖背景）**

- **模型一：房屋交换问题与首选交易环算法（Top Trading Cycles, TTC）**：
  $n$ 个人初始各有一间房，每人对所有房屋有严格偏好排序。每轮让每个剩余的人指向自己当前最喜欢的剩余房屋的拥有者，在形成有向图中必存在至少一个**有向环（Cycle）**。让所有环上的人沿着环路互相交换拿到各自的首选房后退出市场，重复此过程直至全部分配完毕（耗时 $O(n^2)$）。
  - **定理 9.18**：TTC 分配同时满足**个体理性**（Individual rationality，没人分的房比原房差）和**帕累托有效**（Pareto efficiency，不存在使所有人不变差且至少一人变好的重分配）。
- **模型二：男女稳定婚姻匹配与延迟接受算法（Gale-Shapley Deferred Acceptance Algorithm, 1962）**：
  $n$ 个男生与 $n$ 个女生各有完整的严格偏好表。若存在未配成一对的 $(m, w)$ 使得 $m$ 喜欢 $w$ 胜过自己当前伴侣、且 $w$ 也喜欢 $m$ 胜过自己当前伴侣，则称 $(m, w)$ 为**阻塞对**（Blocking pair / Rogue couple）；不含任何阻塞对的完美匹配称为**稳定匹配**（Stable matching）。
  - **Gale-Shapley 求婚-延迟接受算法**：每轮让任意一位单身男生向自己尚未求过婚的女生中最喜欢的一位求婚；女生在当前男友和新求婚者中“择优录取（暂时订婚）”，被甩的男生恢复单身，下一轮继续向自己名单上的下一位女生求婚，直到所有人配对完毕。
  - **定理 9.19**：Gale-Shapley 算法至多经过 $n^2$ 次求婚（耗时 $O(n^2)$）必定终止，且**必然输出一个稳定匹配**！（并且主动求婚方得到的是所有稳定匹配中的最优伴侣，被动接受方得到的是最差稳定伴侣）。

**Problem Statement:**
- **Ex 9.2 (Jump Game I & II)**: 给定非负整数数组 `nums[0..n-1]`（$n \ge 1$），初始位于下标 `0`，在位置 `i` 处最多可向右跳 `nums[i]` 格，目标是到达终点下标 `n - 1`。(1) 设计 $O(n)$ 时间算法判断能否到达终点；(2) 若可达，设计 $O(n)$ 时间算法求出到达终点的最少跳跃次数。
- **Ex 9.3**: 判断下列两种贪心策略是否总能得到最优解，若是请证明，若不是请举出反例：
  (1) 单台机器从时刻 $0$ 开始连续处理若干任务（已知处理时间 $t_j$ 和截止日期 $d_j$），延迟定义为 $L_j = \max\{0, C_j - d_j\}$。如果目标是最小化**所有任务的延迟之和 $\sum L_j$**（而不是最大延迟 $\max L_j$），按截止日期 $d_j$ 从早到晚（EDD）执行是否总是最优？
  (2) 在教室分配问题（要求使用最少的教室举办所有活动）中，如果将活动**按结束时间 $f_i$ 从早到晚排序**，每次将当前活动放入任意一间在 $[s_i, f_i)$ 期间空闲的教室（无空闲则新开一间），是否总能使用最少的教室？

---

**解答与解析：**

**1. 跳跃游戏的 $O(n)$ 贪心算法（Jump Game I & II，Exercise 9.2）**：

- **(1) 判断可否到达终点**：
  维护当前能够到达的最远下标 `far`（初始为 `0`）。从左到右遍历下标 `i = 0 .. n-1`：
  - 若发现 `i > far`，说明连位置 `i` 都跳不到，直接返回 `false`；
  - 否则用当前位置的最大跳跃延伸范围更新最远可达边界：`far = max(far, i + nums[i])`；一旦 `far >= n - 1` 即可返回 `true`。
- **(2) 求最少跳跃次数（分层贪心扩展）**：
  维护三个变量：当前这一跳能够覆盖的右边界 `end`（初始为 `0`）、从当前层所有位置再跳一步能到达的最远下标 `far`（初始为 `0`）、以及跳跃次数 `steps`（初始为 `0`）。
  遍历 `i = 0 .. n - 2`：
  ```c
  int steps = 0, end = 0, far = 0;
  for (int i = 0; i < n - 1; i++) {
      far = max(far, i + nums[i]);
      if (i == end) {      /* 走到了当前步数所能覆盖的边界，必须多跳一步！ */
          steps++;
          end = far;       /* 将下一跳的边界推到最远可达位置 far */
      }
  }
  return steps;
  ```
  每个下标仅被扫描一次，时间复杂度严格为 **$O(n)$**，空间复杂度为 **$O(1)$**。

---

**2. 最小化总延迟与按结束时间分配教室的反例（Exercise 9.3，高频判断题陷阱）**：

- **(1) 最小化延迟之和 $\sum L_j$ 按截止时间排序（EDD）—— 错误（不能保证最优）！**
  - **反例**：设有两个任务，其 `(处理时间 t, 截止时间 d)` 分别为：任务 1 为 `(10, 1)`，任务 2 为 `(1, 2)`。
  - 若按截止时间从早到晚执行（先做任务 1，再做任务 2）：任务 1 在时刻 $10$ 完成（延迟 $10 - 1 = 9$），任务 2 在时刻 $11$ 完成（延迟 $11 - 2 = 9$），**总延迟之和为 $9 + 9 = 18$**；
  - 若反过来先做短任务 2、再做任务 1：任务 2 在时刻 $1$ 完成（延迟 $0$），任务 1 在时刻 $11$ 完成（延迟 $11 - 1 = 10$），**总延迟之和仅为 $0 + 10 = 10 < 18$**！
  （注：单机最小化总延迟 $\sum L_j$ 实际上是 NP-Hard 问题）。
- **(2) 教室分配问题按结束时间 $f_i$ 排序 —— 错误（不能保证最少教室）！**
  - **反例**：设四个活动的时间区间按**结束时间递增**依次为：
    $$
    a = [0, 2), \qquad b = [1, 4), \qquad c = [4, 5), \qquad d = [2, 6)
    $$
  - 按结束时间顺序 $a \to b \to c \to d$ 分配：
    1. $a = [0, 2)$ 放入教室 1；
    2. $b = [1, 4)$ 与 $a$ 冲突，新开教室 2；
    3. 轮到 $c = [4, 5)$：此时教室 1（结束于 $2$）和教室 2（结束于 $4$）**全都空闲**！如果算法任选一间，**不幸把 $c = [4, 5)$ 放进了教室 1**（使教室 1 占用变为 $[0, 2) \cup [4, 5)$）；
    4. 最后轮到长活动 $d = [2, 6)$：它与教室 1 中的 $c=[4,5)$ 冲突，又与教室 2 中的 $b=[1,4)$ 冲突，被迫**新开第 3 间教室**！
  - 而最优分配只需 **$2$ 间教室**（教室 1 放 $a=[0,2)$ 和 $d=[2,6)$；教室 2 放 $b=[1,4)$ 和 $c=[4,5)$）。（注：如果改为按**开始时间**排序，或者按结束时间排序但规定每次总是挑选“**结束时间最晚的可用教室**”，则不会犯错）。

**Problem Statement:**
- **Ex 9.6 (Coin Changing)**: 设硬币面额为幂次序列 $1, c, c^2, \dots, c^k$（整数 $c \ge 2$），每种无限枚。证明每次尽量取最大面额硬币的贪心算法必定使用最少的硬币枚数；再举出一组含面额 $1$ 的一般硬币面额，说明贪心找零不一定最优。
- **Ex 9.7 (Huffman Coding)**: 回答下列问题并说明理由：
  (1) 一棵二进制哈夫曼树共有 $61$ 个节点，它为多少种字符编码？总结点数可能是 $60$ 吗？
  (2) 为 $n$ 种字符构造哈夫曼编码时，最长码长一定不超过 $\lceil\log_2 n\rceil$ 位吗？
  (3) 8 种字符的频数分别为斐波那契数 `1, 1, 2, 3, 5, 8, 13, 21`，其哈夫曼编码的最长、最短码长分别是多少？最多有几种字符的码长相同？
- **Ex 9.8 (田忌赛马)**: 田忌和齐王各有 $n$ 匹马（速度已知），每场各派一匹，快者得 $+1$ 分、慢者得 $-1$ 分、平局得 $0$ 分。设计 $O(n\log n)$ 贪心算法使田忌总得分最大。
- **Ex 9.9 (Maximum Spacing $k$-Clustering)**: 给定 $n$ 个点及两两之间的距离，欲将其划分为 $k \ (2 \le k \le n)$ 个非空类别，使**不同类别之间的最短距离（称为间隙值 Spacing）最大化**。设计贪心算法并证明其与删去最小生成树（MST）中最长的 $k-1$ 条边等价。

**解答与解析：**

**1. 幂次面额 $1, c, c^2, \dots, c^k$ 的贪心找零最优性证明与一般反例（Exercise 9.6）**：

- **证明**：在任何最优找零方案中，对任意 $i < k$，面额为 $c^i$ 的硬币枚数 $a_i$ **严格小于 $c$**（即 $a_i \le c - 1$；否则若有 $c$ 枚 $c^i$，可直接用 $1$ 枚 $c^{i+1}$ 替换，硬币总数减少 $c - 1 \ge 1$ 枚，矛盾）。
  因此，所有小于 $c^k$ 的较小面额硬币所能凑出的最大总金额至多为：
  $$
  \sum_{i=0}^{k-1} (c - 1) c^i = c^k - 1 < c^k
  $$
  这意味着**所有小面额硬币加起来连 $1$ 枚 $c^k$ 都凑不出来**！所以对于目标金额 $M$，最优解中面额 $c^k$ 的硬币枚数唯一固定为 $\lfloor M / c^k \rfloor$，这恰好就是贪心算法的选择！对余数 $M \bmod c^k$ 归纳即证。
- **一般面额反例**：取面额为 `{1, 3, 4}`，目标金额 $M = 6$。贪心算法选 `4 + 1 + 1`（共 **3 枚**），而最优解为 `3 + 3`（仅需 **2 枚**）。

---

**2. 哈夫曼树的节点数奇偶性与斐波那契退化链性质（Exercise 9.7，高频必考题）**：

- **(1) 节点总数关系**：满二叉树中叶子数 $n$ 与内部节点数 $I$ 满足 $I = n - 1$，故总结点数 $N = 2n - 1$。
  当 $2n - 1 = 61$ 时，解得字符种数 **$n = 31$**；由于 $2n - 1$ 恒为奇数，**哈夫曼树的总结点数绝不可能是偶数 $60$**！
- **(2) 最长码长是否不超过 $\lceil\log_2 n\rceil$？** **不一定（错误）**！
  当字符频数相差悬殊时，哈夫曼树会退化为长链，最长码长可达 **$n - 1$** 位（远大于 $\lceil\log_2 n\rceil$）。例如 $n = 4$ 种字符频数为 `1, 1, 2, 4`，码长分别为 `3, 3, 2, 1`，最长码长为 $3 > \log_2 4 = 2$。
- **(3) 8 个斐波那契频数 `1, 1, 2, 3, 5, 8, 13, 21` 的哈夫曼树特征**：
  由于每次合并最小两项之和恰好等于下一项（$1+1=2, \ 2+2=4, \ 4+3=7, \ 7+5=12, \ 12+8=20, \ 20+13=33, \ 33+21=54$），生成的哈夫曼树是一棵**完全退化的单侧长链（高度为 $n - 1 = 7$）**！
  - **最短码长**（频数 `21` 的字符，位于深度 1）：**$1$ 位**；
  - **最长码长**（最底部的两个频数为 `1` 的字符，位于深度 7）：**$7$ 位**（即 $n - 1$ 位）；
  - **最多有几种字符码长相同**：只有最底部深度为 $7$ 的一对兄弟叶子码长同为 $7$，其余深度 $1 \sim 6$ 每层各只有 1 个叶子，故**最多只有 $2$ 种字符的码长相同**。

**3. 田忌赛马贪心双指针策略（Exercise 9.8）**：
将田忌和齐王的马分别按速度从小到大排序，维护双端指针（最慢马与最快马），每轮按以下规则贪心决策（共比 $n$ 场，排序 $O(n\log n)$ + 双指针扫描 $O(n)$）：
1. **若田忌最快的马 $>$ 齐王最快的马**：直接让这两匹最快马比赛，稳赢一场（$+1$ 分）；
2. **若田忌最快的马 $<$ 齐王最快的马**：齐王这匹最快马天下无敌（田忌派谁去都是输），根据贪心止损原则，**派田忌最慢的劣马去消耗掉齐王的最快马**（输一场，保留田忌的主力）；
3. **若田忌最快的马 $==$ 齐王最快的马**（关键分支）：此时再比较双方**最慢的马**：
   - 若田忌最慢的马 $>$ 齐王最慢的马：先让两匹最慢的马比，稳赢一场；
   - 否则（田忌最慢的马 $\le$ 齐王最慢的马）：用田忌最慢的马去对阵齐王最快的马（若田忌最慢马 $<$ 齐王最快马则输掉止损，若全场同速则平局）。

**4. 最大间隙 $k$-聚类（Maximum Spacing $k$-Clustering）与 Kruskal 算法（Exercise 9.9）**：
- **贪心算法**：初始将 $n$ 个点视为 $n$ 个独立的类（连通分量）。将所有点对之间的边按距离从小到大排序，依次运行 **Kruskal 最小生成树算法**：每次取出连接两个不同类别的最短边，将这两个类别合并（类数减 $1$），**一旦剩余类别数降为 $k$（即恰好合并了 $n - k$ 次）就立即停止**！
- **与删去 MST 最长 $k-1$ 条边的等价性**：继续运行 Kruskal 将会把这 $k$ 个类用 $k - 1$ 条更长的边连接成一棵完整的最小生成树（MST）；反过来，先求出 MST 再删去其中最长的 $k - 1$ 条边，得到的恰是完全相同的 $k$ 棵子树（$k$ 个聚类）！
- **最优性证明**：设算法停止后，下一条跨不同类别的最短边长度为 $\lambda$（即当前划分 $C$ 的间隙值为 $\lambda$，而各聚类内部的所有生成树边长均 $\le \lambda$）。对于任意其他 $k$-划分 $C'$，由抽屉原理，必有两个在 $C$ 中属于同一类 $C_r$ 的点 $u, v$ 被 $C'$ 分到了不同类中。沿着 $u$ 到 $v$ 在 $C_r$ 内部的生成树路径（所有边长均 $\le \lambda$）行走，必然至少有一条边跨过了 $C'$ 的不同类别，因此 $C'$ 的间隙值至多为该边长度 $\le \lambda$，证得 Kruskal 聚类全局最优！
